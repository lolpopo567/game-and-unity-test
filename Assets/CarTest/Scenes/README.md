# CarTest scene

1. In Unity 6.6, create an empty scene.
2. Create an empty GameObject named `Car Test Bootstrap`.
3. Attach `CarTestBootstrap` from `Assets/CarTest/Scripts/CarTestBootstrap.cs`.
4. Save as `Assets/CarTest/Scenes/CarTest.unity`, then press Play.

The test track, car, materials, lights, and chase camera are generated at runtime from primitive geometry. This is an isolated engine test with no imported or main-game assets.
