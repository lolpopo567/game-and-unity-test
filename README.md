# Unity Car Driving Test

A small isolated Unity 6.6 driving prototype, separate from the NASA mission-design game. It uses primitive geometry only and contains no main-game assets.

## Run
Open this folder in Unity 6.6, open `Assets/CarTest/Scenes/CarTest.unity`, then press Play.

## Controls
- W / Up: accelerate
- S / Down: brake/reverse
- A / Left, D / Right: steer
- Space: handbrake
- R: reset
